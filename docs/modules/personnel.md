# Personnel

Модуль личного состава предоставляет список, фильтры, поиск, профиль, CRUD и цепочку командования.

Форма создания и редактирования использует пошаговый wizard: основные данные, каскадный выбор назначения, специальности, динамические атрибуты звания и подтверждение.

## API

- `GET /api/personnel` — список с фильтрами, поиском и пагинацией.
- `GET /api/personnel/{id}` — карточка.
- `GET /api/personnel/{id}/profile` — профиль с цепочкой командования.
- `POST /api/personnel` — создание.
- `PUT /api/personnel/{id}` — обновление.

## UI

Назначение выполняется каскадом: армия, соединение, часть, рота, взвод, отделение. Дополнительно доступен прямой поиск подразделения по полному пути.

## Атрибуты

После выбора звания форма получает схему атрибутов и показывает только релевантные поля.
