# Alerts

Alert Center показывает предупреждения по данным текущего scope: отсутствие техники, отсутствие вооружения, пустые или перегруженные сооружения, нехватку специалистов и превышение инвентарных порогов.

Каждое предупреждение содержит действия: открыть объект, перейти к связанным данным, добавить ресурс или открыть Query Terminal.
