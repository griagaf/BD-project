# Alerts

Alert Center показывает предупреждения по данным текущего scope: отсутствие техники, отсутствие вооружения, пустые или перегруженные сооружения, нехватку специалистов и превышение инвентарных порогов.

Каждое предупреждение содержит действия: открыть объект, перейти к связанным данным, добавить ресурс или открыть Query Terminal.

## Business rules

Предупреждения по пустым сооружениям создаются только для объектов, предназначенных для размещения подразделений. Склады, ангары и другие non-assignable сооружения не считаются проблемой из-за отсутствия размещённого подразделения.

## Actions

Если часть не имеет техники или вооружения, alert ведёт в соответствующий модуль и открывает форму добавления. Доступность действия определяется permissions и scope на backend.
