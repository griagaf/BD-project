# Weapons

Модуль вооружения разделяет справочник и наличие в частях.

Справочник содержит категории, типы и динамические атрибуты. Тип вооружения доступен для просмотра независимо от инвентарных назначений. Паспорт типа показывает атрибуты, распределение, связанные части и действия.

## API

- `GET /api/weapons` — наличие вооружения с фильтрами и пагинацией.
- `GET /api/weapons/categories` — категории вооружения.
- `GET /api/weapons/types` — справочник типов.
- `GET /api/weapons/types/{id}/passport` — паспорт типа.
- `PUT /api/units/{unitId}/weapons/{typeId}` — добавить или изменить наличие в части.

## Права

Чтение доступно через `weapon:read`. Изменения проверяются через `weapon:update` и scope военной части. Действия из Alert Center открывают форму добавления с предзаполненной частью.

## UI

Типы вооружения отображаются отдельно от наличия в частях. Пустое распределение не скрывает паспорт типа.
