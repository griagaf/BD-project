# Hierarchy

Модуль иерархии обслуживает армии, корпуса, дивизии, бригады, военные части, роты, взводы и отделения.

Основные возможности:

- lazy-loaded Focus Tree;
- паспорта объектов;
- breadcrumbs;
- создание формирований, частей и подразделений;
- назначение командиров;
- scope-aware filtering.
