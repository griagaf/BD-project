# Equipment

Модуль техники разделяет справочник и наличие в частях.

Справочник содержит категории, типы и динамические атрибуты. Тип техники доступен для просмотра даже без привязки к части. Паспорт типа показывает категорию, описание, атрибуты, количество, распределение по частям и действия.

## API

- `GET /api/equipment` — наличие техники с фильтрами и пагинацией.
- `GET /api/equipment/categories` — категории техники.
- `GET /api/equipment/types` — справочник типов.
- `GET /api/equipment/types/{id}/passport` — паспорт типа.
- `PUT /api/units/{unitId}/equipment/{typeId}` — добавить или изменить наличие в части.

## Права

Чтение доступно ролям с `equipment:read`. Изменение и удаление проверяются через `equipment:update` и область части. `ADMIN_DISTRICT` работает со всем округом.

## UI

Страница содержит вкладки “Наличие в частях” и “Справочник типов”. Диалог добавления использует searchable select по всем доступным частям, включая части без текущей техники.
