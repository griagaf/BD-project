# Buildings

Модуль сооружений управляет зданиями военных частей и размещением подразделений.

Сооружение имеет признак возможности размещения подразделений. Backend и триггеры БД запрещают назначение неподходящего сооружения, назначение в чужую часть и повторное активное размещение подразделения.

## API

- `GET /api/buildings` — список сооружений.
- `POST /api/buildings` — создание.
- `PUT /api/buildings/{id}` — обновление.
- `PUT /api/buildings/{id}/subdivisions/{subdivisionId}` — разместить подразделение.
- `DELETE /api/buildings/{id}/subdivisions/{subdivisionId}` — снять размещение.

## UI

Карточка сооружения показывает статус “Можно закреплять подразделения” или “Нельзя закреплять подразделения”, список размещённых подразделений и доступные действия.
