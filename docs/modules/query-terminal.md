# Query Terminal

Intelligence Query Terminal выполняет шаблоны на основе SQL-запросов из `selects`. Пользователь выбирает шаблон и параметры через форму, видит псевдокоманду и получает таблицу результатов.

Результаты пагинируются на frontend. Ошибки отображаются через отдельную панель без раскрытия raw SQL и stacktrace.
