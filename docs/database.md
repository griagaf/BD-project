# База данных

## Источники структуры

`create.sql` содержит основную модель данных: иерархию формирований, части, подразделения, личный состав, звания, специальности, технику, вооружение, сооружения, пользователей, роли, назначения, аудит и служебные таблицы.

Каталог `selects` содержит аналитические SELECT-запросы для Intelligence Query Terminal. Каталог `triggers` содержит функции и триггеры, подключённые через Flyway migrations.

## Динамические атрибуты

Техника, вооружение и звания используют attribute-driven модель:

- категории определяют набор атрибутов;
- attribute types задают имя и тип данных;
- values хранят значения для конкретного типа техники, типа вооружения или военнослужащего;
- frontend получает metadata schema и строит формы без hardcoded полей.

## Триггеры

Триггеры БД используются для целостности данных, аудита и бизнес-ограничений. Назначения подразделений на сооружения дополнительно защищены правилами:

- подразделение имеет одно активное размещение;
- подразделение и сооружение относятся к одной военной части;
- сооружение должно поддерживать размещение подразделений.

## Seed data

Seed data полностью русскоязычный и покрывает роли, иерархию, личный состав, инвентарь, предупреждения, отчёты, readiness и Query Terminal.
