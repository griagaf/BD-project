# Readiness

## Назначение

Readiness показывает состояние текущей области командования в виде общего балла и направлений: личный состав, техника, вооружение, специалисты, инфраструктура и предупреждения.

## Интерпретация

- Высокая готовность означает отсутствие критических предупреждений и достаточное покрытие ключевых ресурсов.
- Средняя готовность показывает наличие отдельных проблем, которые не блокируют функционирование области.
- Низкая готовность отражает критические предупреждения, дефицит ресурсов или проблемную инфраструктуру.

## UI

На Dashboard доступна раскрываемая панель “Критерии оценки готовности”. Она объясняет показатели понятным языком и помогает понять, почему область получила текущий статус.
