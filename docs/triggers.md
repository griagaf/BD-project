# Триггеры

## Назначение

Триггеры PostgreSQL обеспечивают целостность данных и фиксируют правила, которые должны соблюдаться независимо от клиента.

## Размещение подразделений

Для назначений подразделений на сооружения действуют правила:

- одно подразделение имеет только одно активное размещение;
- подразделение и сооружение относятся к одной военной части;
- сооружение должно поддерживать размещение подразделений.

Backend выполняет предварительную проверку и возвращает понятную ошибку. Триггер БД защищает данные от некорректных операций в обход API.

## Интеграция

Функции и триггеры из каталога `triggers` подключены через Flyway migrations и применяются при запуске контейнера backend.
