# Динамические атрибуты

## Назначение

Динамические атрибуты позволяют описывать разные категории техники, вооружения и званий без жёстких полей в коде.

## Техника и вооружение

Категория определяет набор атрибутов. Тип хранит значения этих атрибутов. Например, автоматическое оружие имеет калибр и ёмкость магазина, а инженерная техника — рабочее оборудование и производительность.

## Звания

Каждое звание имеет собственный набор атрибутов. Форма военнослужащего перестраивается после выбора звания и показывает только релевантные поля.

## Frontend rendering

Frontend получает описание схемы, определяет `dataType` и рендерит text, number, date или boolean controls. Паспорт объекта использует то же описание полей.
