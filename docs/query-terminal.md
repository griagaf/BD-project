# Query Terminal

## Назначение

Intelligence Query Terminal выполняет согласованные аналитические SQL-шаблоны и показывает результаты в интерфейсе без раскрытия пользователю технических файлов и raw SQL.

## Поток выполнения

1. Frontend получает описание шаблонов.
2. Пользователь выбирает шаблон через поисковый список.
3. Форма параметров строится по описанию шаблона.
4. Backend проверяет permissions и scope.
5. SQL выполняется через `NamedParameterJdbcTemplate`.
6. Результаты возвращаются таблицей с колонками и строками.

## UX

Список шаблонов не пагинируется, потому что набор ограничен и удобнее воспринимается единым списком с поиском. Пагинация используется только для результатов выполнения.

## Ошибки

Ошибка запроса не сбрасывает выбранный шаблон и параметры. Frontend показывает Error Panel с понятным сообщением и кнопкой повторного выполнения.
